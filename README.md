# Back-end

Este é meu repositório de estudos sobre back-end, a parte de uma aplicação que cuida dos dados, das regras de funcionamento e da comunicação com o servidor.

Reúno aqui dicas, tutoriais e anotações do que estou aprendendo. A ideia é registrar meu progresso e criar um material de consulta que também possa ajudar outras pessoas.

## Conteúdo atual

Os primeiros materiais estão na pasta [Supabase](Supabase):

- [Passos iniciais](Supabase/Passos%20iniciais.md): anotações sobre a criação de uma conta e os recursos do painel.
- [Tipos de dados do PostgreSQL e do Supabase](Supabase/tipos%20de%20dados%20Postgre%20%26%20supabase.md): material de apoio para os estudos de banco de dados.

## Como consultar

Abra os arquivos diretamente pelo GitHub e navegue pelos assuntos. Para ler as anotações, basta acessar os documentos; não há uma aplicação para instalar.

## Em desenvolvimento

O conteúdo ainda está sendo organizado. Algumas páginas foram iniciadas e serão preenchidas conforme eu avançar nos estudos. Novas dicas, explicações e exemplos serão acrescentados ao repositório.
